atlink

Paste a bsky.app post URL or an at:// URI — the other form comes back, no network calls.

Output
authority
collection
rkey

This authority is a handle, not a DID. A handle-authority at:// URI is not the canonical form — the canonical AT URI for a record always addresses it by DID. Turning this handle into its DID (or a DID back into a handle) needs a network lookup, which this page deliberately does not do.

Examples

How an AT URI is structured

An AT URI has the shape at://<authority>/<collection>/<rkey>. The authority is a DID or a handle identifying a repo; the collection is the NSID of the record type inside that repo (a Bluesky post is always app.bsky.feed.post); the rkey is the record's key within that collection. A bsky.app post URL encodes exactly the same three things as bsky.app/profile/<authority>/post/<rkey>, with the collection implied rather than written out.

This page only parses strings you give it. It cannot resolve a handle to a DID or confirm a record actually exists — both would require a call to a PDS or a directory service.
