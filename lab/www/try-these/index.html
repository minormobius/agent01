Try These

This page has no network access of its own — it cannot reach poly.pizza or opengameart.org, at build time or while you're looking at it. What it can do: read a real Wavefront .obj file you already have, UV-map and texture it, and drop it into a spinning gallery. Two low-poly stand-ins (not the real downloads — see below) start things off.

or drag a .obj file anywhere on this page

Download from poly.pizza or opengameart's OBJ button (no account needed, exactly like the request that started this page) and drop the file back in here.

Drag any model to spin it. They turn on their own until you touch one, and hold still instead if you've asked your device to reduce motion.

"Bot" and "Cottage" are built here from plain boxes and cones, not downloaded from anywhere — this build had no way to fetch poly.pizza's actual Robot or Farm House models (their download button needs a click no automated fetch here can make, and a raw opengameart.org file link truncates long before any face data survives the size budget). Anything you add yourself is parsed by a from-scratch OBJ reader written for this page: it reads real v/vt/f lines (n-gons fan-triangulated, negative indices resolved), and if a file has no usable UVs it gets one generated by projecting each triangle onto whichever axis its face normal points away from most. Textures are drawn on a <canvas>, never loaded from a file. Built with three.js.
