Combine This

Mints an invented single-syllable word, or finds a real one, in the spirit of rite.mino.mobi/sharp. Pairs it with a real top-level domain — checked against a known-registry list, not guessed. Then, instead of pretending to know if the name is taken, it links straight out to a genuine public WHOIS lookup for that exact string.

Honest limit: this page cannot ask a registrar anything itself. The lab worker's Content-Security-Policy only lets it talk to Bluesky's API and plc.directory — no WHOIS server, no registrar API. So "verify" here means two real, offline checks (is the label a legal domain label, is the TLD one I can confirm actually exists) plus a link to a real live lookup. Nothing on this page claims a domain is free or taken.
