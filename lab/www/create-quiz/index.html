minutiae

a quiz about one Bluesky account, built entirely from its own numbers

Type a handle. We pull its recent posts and compute real statistics from them — the hour of day it posts most, the median post length, the single most-repeated word, the exact gap between two of its posts. Then we ask you which real number is which. Following the account does not help. Reading every post does not help much either.

Built from up to the 100 most recent visible posts the public API returns, not the account's full history — so this is a quiz about a recent window, not a lifetime. Scores are out of however many distinct questions that window supports, usually ten.
