monopath

Cover every vertex with vertex-disjoint monochromatic paths — one colour per path, built by clicking. Try to do it in r paths or fewer.

Gyárfás conjectured in 1989 that any complete graph with its edges coloured in r colours can always have every vertex covered by at most r vertex-disjoint paths, each one a single colour. Pokrovskiy proved it true for r = 3 and 4 — the instance below is one of those solvable cases, so a clean win really is on the table. But for large r the conjecture is false: there are colourings that need at least (1−o(1))·r·log log r paths, a count that keeps growing faster than r however big r gets.

Said plainly: log log r grows so slowly that no graph that fits in a browser tab will visibly show that gap — you will not watch the disproof happen here. What this page can honestly offer is the other half: try to cover this graph in r paths, on instances small enough that r is provably achievable (r=3, r=4) and larger ones where nobody — including this page — knows the true minimum. Finding it is a real, unsolved-per-instance search problem, not a demo.
