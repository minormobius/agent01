mino.mobi / minomobi

the factory

Ask for a website on Bluesky. An agent builds it. It lives here, under a name you pick.

How it works

1. You tag the bot with what you want built.
2. The name is reserved and an agent writes the site — no human in the loop.
3. A gate checks it only touched its own directory, then it deploys.
4. The bot replies with your URL. Reply again to change it.

Your name, and it stays yours

You choose what your site is called and minomobi.com/<name>/ keeps resolving. Reply in the same thread to change the site — same name, same URL, new version. Every card links back to the thread it was asked in, so “request a change” is a reply, not a form.

Previews run sandboxed

Preview opens a site in a frame on this page, and that frame is sandboxed into its own origin — the listing you are reading and the site you are previewing cannot see each other, which is what makes it safe to run a stranger’s code next to it. The cost is real and worth knowing: a site that stores anything, or fetches its own data, may come up empty in the frame. Open is the whole site.

One house style

Every tenant links a shared kit — the same palette, the same inputs and buttons, the same error treatment — so a hundred sites by a hundred people still look like one place. The factory also remembers what you tend to ask for, so your second site starts closer to your taste than your first.

Why this domain and not mino.mobi

Everything here is written by an agent, so it lives on its own domain — minomobi.com shares neither login cookies nor reputation with mino.mobi, where the hand-built things live. Nothing generated here can reach a signed-in session there, and if a generated page ever earns a bad reputation it is contained to this domain.
