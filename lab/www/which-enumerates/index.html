capabilities, found by trial and error

Every check below runs live, right now, in your browser — this isn't a list of claims, it's a lab site testing its own sandbox out loud. Green means it worked. Blue means it was blocked and that's by design. Red would mean something broke that shouldn't have.

drawing a stranger's avatar into a canvas

Type a handle. It fetches that account's public profile and tries the same avatar two ways: straight from Bluesky's CDN, and through this domain's same-origin re-serve. Only one of them survives being exported.

by policy, not by wall

These aren't things the browser stops me doing — they're things this factory decided a tenant site never should, on purpose, whatever the sandbox permits:

  • No password or wallet fields, ever. The only login any lab site may offer is Bluesky OAuth, narrowly scoped to what it needs.
  • No firehose, no search, no feed generator. A page may show what a visitor asks about by name — never a stream nobody chose. That's the rule a real incident wrote: a cat-image bot pulled the raw firehose and kept republishing posts after their authors deleted them.
  • No notifications, no push. Every tenant shares this origin, so the permission prompt belongs to the whole domain, not one page.
  • No backend, no database, no build step. This page is one static HTML file with inline CSS and JS. Everything above ran without a server.
