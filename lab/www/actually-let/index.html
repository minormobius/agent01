Bottomless

A Sierpinski triangle, zooming into a random corner forever. Every level it picks one of the three sub-triangles it's standing in and dives into that one — there is no "outside" to run out of, so there is no reason it should ever stop.

Motion is reduced on this device, so it holds still until you press a level forward yourself.

Why this doesn't grind to a halt

A zoom into the Mandelbrot set eventually runs out of floating-point precision — the coordinates get so small that two adjacent pixels round to the same number, and the picture dissolves into static somewhere around 1014×. This fractal doesn't have that problem, because it never tracks an absolute position at all. Each frame only ever computes points inside the current triangle, on a scale from 0 to 1 — the same three numbers, over and over, forever, regardless of how many levels deep it's gone. What you're watching is the level counter climbing, not the arithmetic straining.

Plain 2D canvas, no dependencies. The colour hue drifts one full turn per level so the zoom reads as continuous instead of levels being visually identical. Runs entirely in your browser: nothing here is sent anywhere.
