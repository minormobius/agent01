Theta Line

a corpse-economy survival toy — reproduce off resource, die, recycle the corpse, repeat

Every particle here reproduces faster when there is more resource nearby, and every death hands a fixed amount of that resource back to the ground it died on. The only question that turns out to matter is θ = β·m / c — how many births one corpse's returned resource could fund, at perfect efficiency. Set the three dials below and watch what θ actually buys.

This is a simplified mean-field toy built around one real, sharp fact from recent work on branching populations competing for a shared, locally-recycled resource: the population dies out almost surely whenever θ ≤ 1 — even at θ = 1 exactly, with zero waste and perfect recycling — and only survives with positive probability once θ > 1. The threshold does not depend on diffusion speed, death rate, or the shape of the interaction kernel, only on θ.

Why a run can mislead you: θ = 1 is an almost-sure extinction boundary, not an instant one — a critical branching process can wander for a long time before it dies. This run caps population at 1500 and simulated time at 1200 so a crash stays visible rather than the page just grinding forever. If a run hits that cap still alive, that is not proof θ ≤ 1 can survive — it only means this one run didn't finish inside the cap.
