What the ribbon actually is

P¹ has two charts: U₀ = {z₀≠0} with coordinate t = z₁/z₀, and U₁ = {z₁≠0} with coordinate s = z₀/z₁ = 1/t. O(n) is trivial on each chart alone — pick a local frame vector on U₀ and one on U₁ — and the two frames are related on the overlap by the transition function

g₀₁(t) = t³ — the cocycle that defines O(n)

The grey ring below is the real locus of P¹(C) — the circle t = e^{iθ}, θ running once around. The coloured ribbon tracks a single real frame direction as it is carried around that loop by g₀₁: its angle turns by n·θ, so after one full lap (θ: 0 → 2π) it has rotated by exactly 2πn — a whole number of turns, which is why the ribbon always closes up smoothly no matter how hard it's twisted. The winding count you can see is literally n, the same integer that is O(n)'s degree (its first Chern class).

Honest limit: the actual fibre of O(n) is a complex line — two real dimensions — so the true total space over this one real circle is 3-real-dimensional and the full thing over all of P¹(C) is 4-real-dimensional. Neither embeds faithfully in the screen. What's drawn is the real span of one trivializing frame vector, which carries the winding number honestly but throws away the phase orthogonal to it — a deliberate simplification, not an approximation error.

Cohomology — Riemann–Roch on P¹

h⁰(O(n)) = 4 h¹(O(n)) = 0 χ = h⁰ − h¹ = 4 (should equal n+1 = 4)

deg O(n) = n, genus of P¹ is 0, so Riemann–Roch says χ(O(n)) = n + 1 unconditionally. h¹ comes from Serre duality, h¹(O(n)) = h⁰(O(−n−2)), which is positive only once n ≤ −2 — O(−1) is the one twist with no cohomology at all, in either degree.

Global sections — a basis of H⁰(P¹, O(n))

Sections of O(n) are degree-n homogeneous polynomials in z₀, z₁. For n ≥ 0 that space has dimension exactly n+1, spanned by the monomials below; for n < 0 there are no nonzero global sections at all — a twisting sheaf that's twisted the wrong way has nothing to hold onto.
