The lyrics below are generated for this page. Music is synthesized live in your browser with the Web Audio API — oscillators standing in for pads, bass and a soft beat, not a recording. Every few words of the lyrics are mapped to one emoji from a fixed pool of 100; a handful of words are mapped on purpose (fire → 🔥, night → 🌙…), everything else falls to a deterministic hash so the same words always land on the same emoji.
