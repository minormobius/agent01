wingfold

Draw on the left plane. The right plane shows the same points run through the Joukowski transform, w = z + k/z — the map that turns a circle into an airfoil, which is why the classic demo below is a circle, not a scribble.

z-plane — draw here (mouse or finger)

w-plane — w = z + k / z, live

z = 0 is a pole of the map — 1/z blows up there. Any stroke that passes near the origin (small red ring on the z-plane) is cut where it gets too close; the w-plane can't show what doesn't converge to a point.

The w-plane's axis range is fit automatically to whatever you've drawn — strokes near the pole map to huge values, so a fixed scale would either clip them or make everything else microscopic.
