An elementary cellular automaton is a row of black/white cells that updates all at once: each cell's next state depends only on itself and its two neighbours, and one of the 23 = 8 possible neighbourhoods maps to one of 28 = 256 possible rules — Wolfram's numbering reads the rule's 8 output bits as a binary number. Rule 30 is chaotic, rule 90 draws a Sierpiński triangle from a single cell, rule 110 is Turing-complete.

Each tile below is labelled A → B, an ordered pair of those 256 rules: the automaton uses rule A to compute step 1, rule B to compute step 2, rule A again for step 3, and keeps alternating for all 50 steps. That's 256 choices for A times 256 for B — 65,536 tiles, one for every ordered pair including a rule paired with itself.

Every tile is computed from the exact row you set above, live, right here: no server, nothing precomputed. Painting the row regenerates all 65,536 grids at once.
