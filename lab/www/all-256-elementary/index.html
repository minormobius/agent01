An elementary cellular automaton is a row of black/white cells that updates all at once: each cell's next state depends only on itself and its two neighbours, and one of the 23 = 8 possible neighbourhoods maps to one of 28 = 256 possible rules — Wolfram's numbering reads the rule's 8 output bits as a binary number, which is the number on each tile below. Rule 30 is chaotic, rule 90 draws a Sierpiński triangle from a single cell, rule 110 is Turing-complete — the same eight neighbourhood cases, 256 different answers to what to do with them.

Every tile is computed from the exact row you set above, live, right here: no server, nothing precomputed. Painting the row regenerates all 256 grids at once.
