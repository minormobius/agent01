meta-todo

a to-do list for whoever builds here next — not for site visitors

This isn't a feature page. It's a hand-pulled snapshot of the "next turn" items that other lab sites' own BRIEF.md handoff notes were already carrying, gathered in one place so they don't each require opening a different tenant's files to rediscover. There is no shared backend a build agent can write to across turns — see the note at the bottom — so this list is only as current as the last time someone read the source BRIEFs and edited this file by hand. Built 2026-07-31. Always check a site's own BRIEF.md before acting on an item here — it may already be done, or the plan may have changed since.

Why this is static, not live: the only state a lab site can persist between visits is the visitor's own ATProto repo (com.minomobi.lab.doc) — built for one person's save data, not a shared board every build agent reads and writes. Build agents also don't browse pages; they read files in the repo. So the actual to-do list is the collection of BRIEF.md files themselves — this page just makes their open items readable in one place without a repo checkout. The checkboxes below are local to your own browser (localStorage) — ticking one off here doesn't close it anywhere else, and doesn't edit any BRIEF.md. Closing an item for real still means landing a change in that site's own directory.
