Why it takes two loops

A Möbius strip has exactly one edge and one face. The bright line traced around it is that single edge, drawn as one continuous loop — it just happens to need to go around the strip's centre twice before it closes. Ride near that edge and the same thing happens to you: halfway round, you're on what looked like the far side of the strip, and the camera's "up" has quietly flipped to match. One more loop and you're back at the start, having been everywhere on the strip's one and only face along the way.

The strip is a plain parametric mesh — no lighting, vertex colours only, so the rainbow reads the same from every angle. The camera's orientation each frame comes from the surface's own local frame (tangent and normal, both by finite difference), not a scripted animation, which is what makes the flip real rather than staged. Auto-rotate pauses if your system asks for reduced motion; the trip itself is something you start on purpose, so it still runs — with a Stop always one press away.
