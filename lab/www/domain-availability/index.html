domain availability

Type a name — see it across a curated set of 100+ TLDs, validated instantly, with one tap out to the real registry record for whichever ones interest you.

This page cannot check live availability itself. The lab's content-security policy only lets a page here talk to Bluesky's API — no WHOIS server, no registrar, no RDAP endpoint is reachable by fetch from this origin. So instead of guessing, every result links straight out to IANA's own record for that TLD and to a live RDAP lookup that opens in a new tab. What happens here, in your browser, is instant: is the name even a legal domain label, and what do we already know about that ending.

What "public info" means here

The badges and notes on each TLD are a static reference collected when this page was built — kind of TLD, whether it's commonly used as a "domain hack" (like .io, .ly, .gg), and whether registration is restricted to an eligible group or requires a local presence. They are not live registry data and registry operators change hands over time, so treat them as a starting point, not a guarantee — the linked-out RDAP and IANA pages are the source of truth.

RDAP is the modern replacement for WHOIS; not every registry supports it yet, so a lookup that comes back empty for a ccTLD isn't necessarily proof of anything — check the registry's own site if it matters.
