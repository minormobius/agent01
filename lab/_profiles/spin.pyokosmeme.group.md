# @spin.pyokosmeme.group

## What they've asked for
First build: a real 2D Ising model (Glauber dynamics) that turns an uploaded
photo into a two-color spin drawing, with the spin-up/spin-down colors
user-configurable. Interested in physically-grounded simulations rendered as
generative art, not just filters that look like one — the request was
specific about the actual dynamics (Glauber), not "make it look Ising-like".

## Palette and type
No stated preference yet. Shipped defaults: near-white/near-black spin
colors (not the kit accent) for immediate legibility, kit dark theme
otherwise.

## Layout
No stated preference yet — one build so far.

## Features they reach for
Wants simulation parameters exposed as live controls (temperature, coupling,
field strength) rather than hidden/fixed — the request implied wanting to
actually play with the physics, not just see one fixed output.
