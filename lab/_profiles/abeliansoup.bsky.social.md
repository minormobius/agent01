# @abeliansoup.bsky.social

## Tone
Writes in a theatrical, slightly dry register ("please resolve as a matter
of great haste", "exeunt!"). A playful, unfussy voice in copy and NOTE.txt
replies lands better than a flat status report.

## What they reach for
Reported a bug (avatars failing to load on `more-latter`) rather than asking
for a new feature — cares that the thing already promised actually works.
Wants root cause named, not just "fixed it", when something breaks.

## Said no to
Nothing yet on record.

## Not every post is a request
Sometimes shows up in-thread as banter or a question aimed at someone else
(e.g. asking a third party which Claude model built the last few turns),
not a technical ask. Don't invent work against the plan when a turn's post
doesn't point anywhere — answer directly via NOTE.txt if there's something
real to say, and leave the code alone.
