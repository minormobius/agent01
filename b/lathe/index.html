the toy mill — social analysis, generated

The forty-odd social toys scattered across this domain are not forty ideas. They are forty points in one small space: each binds some accounts, pulls them through a reader of public data, squeezes them with a measurement or two, and draws the result. unique is posts → phrases → a ranked table. squares is follows → a grid of faces. web is posts → link co-occurrence → a force graph.

So this doesn't write the forty-first toy. It writes the space, and walks it. Every stage declares what it consumes and what it emits, and toys are built by a typed walk — so a generated toy is correct by construction, certified by the same oracle, and permalinked by its seed: toy № 4,891 is the same toy on any machine, for ever.

    The proof

    The claim is falsifiable, so here it is tested: each of these is a toy that actually exists on this domain, written by hand, months apart — re-expressed as a genome and run through the same oracle that certifies the generated ones. If the space were made up, they wouldn't fit.

    The vocabulary

    Every part below has a real executor running against public, CORS-open Bluesky endpoints — nothing here is aspirational, because a permalink that can't run is worse than no toy. A node selftest asserts the generator's vocabulary and the runtime's implementations are the same set.

    How a toy is minted. The seed fixes a subject, a source that supports it, a chain of one or two lenses whose input type matches whatever the previous stage emitted, and a view that can draw the port it ended on. Type-compatibility at every step is what turns a random draw into a working toy; an independent oracle re-checks the result before it ships. A minority of toys carry a sink — a write back to your own repo — and those request exactly the OAuth scope their sink implies, so the consent screen is as narrow as the toy is. Read-only toys never ask who you are. Deterministic (xmur3 + mulberry32), no build step, no backend · kin to fable/morph and borges · part of b.mino.mobi.
