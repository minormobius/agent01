sleuth.

a thousand posts, searchable in a second

Pulls an account's last thousand posts into this tab and indexes them here, so search is instant and needs no key at all. Add your own API key and the same retrieved posts become context: ask a question and get an answer built from what they actually wrote — or generate a dossier of themes, narrative arcs and a personality read, every claim cited back to the post.

Bring your own key. It goes straight from this tab to the provider and never touches a server here — requests are made by your browser. It is kept in sessionStorage, which is deliberate: closing the tab forgets it, so a key cannot outlive the sitting. Search and the whole index work with no key; a key only adds the answering and the dossier.

Posts are read from the account's own PDS over the public API — no sign-in, nothing stored, and the index lives in this tab. Moved here from photo, where it was filed as an image tool by accident.
