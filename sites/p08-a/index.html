how an AT URI is shaped

at://<authority>/<collection>/<rkey> — the authority names a repo (a handle like alice.bsky.social, or a DID like did:plc:…), the collection is the record type's NSID (a Bluesky post is app.bsky.feed.post), and the rkey picks one record out of that collection. A bsky.app post link is just a friendlier spelling of the same three parts, with the collection implied by the word "post" in the path.

An at:// URI with a handle authority is not the canonical form — the canonical form always uses the DID, because a handle can be repointed to a different DID later and a permalink shouldn't move when that happens. Turning a handle into its DID (or back) needs a directory lookup, and this page deliberately makes no network calls, so it leaves the authority exactly as you gave it.
