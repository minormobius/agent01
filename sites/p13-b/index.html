1 · escape-time map click anywhere to seed an orbit there

Every pixel is its own starting point z₀. Color = how many iterations before |z| exceeds 6 (bright = fast escape); the darkest fill means it stayed under that radius for all 60 steps. Growth here is additive (driven by ±cos θ per step), not multiplicative like z²+c, so the escape radius is an empirical choice tuned to show structure, not a theorem — treat the boundary as approximate.

4 · bifurcation diagram

For each c on the x-axis, iterate from a fixed off-axis z₀=0.3+0.4i for 250 steps, discard the first 150 as transient, and plot the remaining |zn| values (capped for display — this map's orbits drift rather than settle for most c, so large values pile at the ceiling instead of a clean line). Vertical spread at a given c means the orbit is still moving, not settled to a fixed point. Drag on the chart to jump the c slider.
