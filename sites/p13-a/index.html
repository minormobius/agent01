Driftmap

an orbit explorer for zn+1 = (r + cosθ)eiθ − c

zn+1 = (r + cosθ) eiθ − c
  • r = |zn| — the magnitude of zn
  • θ = arg(zn) — the angle of zn
  • c ∈ ℝ — a real constant, fixed per run

Plots z₀ through zN in the complex plane, coloured early→late. Tap or click the plane to set a new z₀ there. The path stops early if it exceeds the escape radius many times over — that point is diverging, not a bug.

Every pixel is its own z₀ on this plane, iterated at the current c. Colour = iterations until |z| passes the escape radius; the dark interior never escaped within a fixed cap of 60 iterations — a boundary drawn to that depth for speed, not a proof of boundedness. Tap or click to jump the orbit view to that point.

rn = |zn| (top) and θn = arg(zn) (bottom, wrapped to [−π, π]) against iteration n, for the same orbit as the orbit view.

For each c across the range, z₀ is iterated 200 times to clear transients, then the next 60 values of Re(z) are plotted as a column at that c. The vertical accent line marks the c set above. Fixed depth of 260 iterations per column, chosen for responsiveness — deep periodic windows narrower than one pixel column can be missed.
