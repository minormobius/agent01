The rule

The first segment is unit length, fixed, horizontal. The second is unit length too, dropped at a random angle so that it passes through — not ends at — one endpoint of the first: that endpoint is now touched, and the second segment's own two ends start out free. From there, every new segment is also unit length, and is built along the exact straight line through two free endpoints that belong to two different existing segments, extended past both of them so each becomes an interior touch point on the new segment rather than a shared corner. It is checked against every other segment for intersections and thrown away if it crosses anything, so the whole picture stays a tangle of touches with no true crossings anywhere.

Two points can only be joined this way if they are within one unit of each other in a straight line with nothing in between — so the process is finite by construction, and pressing "add" can legitimately fail to find room.

One reading, stated plainly: the prompt only specified unit length for the very first segment. Every later segment is unit length too here, because that's the one choice that makes "touch two free endpoints along its length" fully determined rather than leaving the new segment's own length as a free extra parameter.
