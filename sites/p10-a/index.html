How this reads "interaction"

There is no interaction-graph endpoint to ask, so this is a proxy built from each account's last 100 posts (app.bsky.feed.getAuthorFeed): a repost or a quote of someone counts for 3, a reply counts for 2, an @-mention counts for 1, added up per account and ranked. It is a read of recent public behaviour, not a lifetime total, and a quiet account will show a thin or empty circle rather than a guess.
