Vacancy

Sweep one name across a wide spread of top-level domains — legacy, restricted, modern gTLD, and country-code — and jump straight to a live lookup for each one.

This page cannot check live registry availability itself. It runs under a content policy that only allows it to talk to Bluesky's servers — no WHOIS, no RDAP, no DNS lookup host is reachable from here, so there is no honest way for this page's own code to tell you a name is taken or free. Rather than fake that answer, it does the parts it can do for real — check the name's syntax and each TLD's registration rules, and show what's actually known about the registry — and hands you a one-tap link to a real, live WHOIS lookup for the exact name you typed. The check itself happens on the other side of that link.

Reference facts here are static and curated at build time — not a live query. Eligibility rules especially can change; the linked lookup is the source of truth, this page is the shortcut to it.
