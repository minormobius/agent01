what's canonical

An at:// URI's authority can be a handle or a DID, but only the DID form is canonical — a handle can be renamed or reassigned to a different account, a DID can't. When this page produces an at:// URI from a bsky.app link, the authority is whatever the link contained: if that was a handle, the result is a working but non-canonical URI. Turning a handle authority into its DID (or back) needs a directory lookup (com.atproto.identity.resolveHandle / PLC directory), and this page deliberately makes no network calls, so it won't do that resolution for you.

only app.bsky.feed.post permalinks are supported — other collections are reported as unrecognised.
