PARTY ROOMS · 2+ PLAYERS

Start a room and you get a 4-character code. Post the join link on Bluesky: friends sign in with their handle and play from their phones while the TV view shows the shared screen.

Each cabinet is playing a few seconds of the real game. Seven of them are the pressure family: games about deciding under pressure, each of which measures something different about the decision. Party rooms run on Cloudflare Workers + Durable Objects, with Bluesky sign-in via auth.mino.mobi, and a party game is a markdown file in games/games/ that anyone can write. See the repo.
