Blind pairs

Sites built twice for the same Bluesky request — once by the build-a-bot as it runs in production, once by a challenger harness — under neutral names, for a blind vote. Which builder made which is kept elsewhere until the votes are in.

These pages are served from this host, not from imp.mino.mobi, for the same reason the build-a-bot publishes to minomobi.com: model-written code does not run inside the mino.mobi sign-in's site.
