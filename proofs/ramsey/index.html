Tap an edge to flip it between red and blue. The extremal colouring uses n − 1 red groups of m − 1 people, blue between them, on (m − 1)(n − 1) vertices. No red cycle can have m vertices, because each red group is too small, and no blue clique can have n, because there are only n − 1 groups. The theorem says that one more vertex always breaks it. Add one and try to colour its edges so that nothing appears.

This is a plain exhaustive search with no theory in it. It builds graphs one vertex at a time and keeps those with no red C_m and no blue K_n. Both properties pass to subgraphs, so every good graph on N vertices is reached. The first N with none left is R(C_m, K_n). These small values have been known for decades; the 2026 claim is about all of them. The last two cases take about 15–25 seconds.

Starting…

The proof reduces everything to graphs with no cycle of length k + 1 = m, few independent vertices, and a clique Q of order t. Only 5 ≤ k ≤ 17 and t ≤ 8 are left for a computer. There, a pattern records how paths between clique vertices, outside the clique, can hang together. Rules proved in the paper (extension, required paths, ball bounds, packing, strengthening) must then reach a contradiction for every pattern. This page implements those rules again from the paper's text, in about 300 lines of JavaScript, without translating the release's Python. It runs them on every pattern, and checks the result against the release's deduction traces: every outcome, every initial forbidden-flag matrix, every round of added prohibitions, and every witness. Tap a cell to inspect its pattern.

The question

The Ramsey number R(C_m, K_n) is the least N such that every red–blue colouring of the edges of the complete graph on N vertices contains a red cycle through exactly m vertices or a blue clique on n vertices. In 1978 Erdős, Faudree, Rousseau and Schelp conjectured that it equals (m − 1)(n − 1) + 1 whenever m ≥ n ≥ 3, apart from R(C₃, K₃) = 6. Before 2026 the conjecture was proved piece by piece:

  • for n = 3 by Chartrand and Schuster (1971);
  • for m ≥ n² − 2 by Bondy and Erdős (1973);
  • for n = 4, 5, 6 and 7, by four different groups between 1999 and 2008;
  • for large m by Nikiforov (2005);
  • and, by Keevash, Long and Skokan (2021), everywhere beyond an unspecified constant, which left finitely many unknown cases.

The 2026 claim

A paper dated 25 September 2026, released on 6 October in a collection of 722 model-written papers, proves the full conjecture. Most of it is structural. It shows that a minimal counterexample has an expansion property, contains a large clique, and has path systems that cannot be improved. A finite search over 3,099 patterns settles the rest. It does not search over graphs or colourings.

What Lean covers

The release's Lean library proves the entire main theorem. Its scope note calls it "the complete parameter range of the paper's main theorem". The paper is not in the release's formalization catalogue, which is why the tagline says uncatalogued. The statement, verbatim:

def RamseyProperty (m n N : ℕ) : Prop :=
  ∀ G : SimpleGraph (Fin N),
    SimpleGraph.cycleGraph m ⊑ G ∨ (⊤ : SimpleGraph (Fin n)) ⊑ Gᶜ

theorem thm_main :
    (∀ m n : ℤ, n ≤ m → 3 ≤ n → (m, n) ≠ (3, 3) →
      (cycleCliqueRamsey m.toNat n.toNat : ℤ) = (m - 1) * (n - 1) + 1) ∧
    cycleCliqueRamsey 3 3 = 6

Here G is the red graph and its complement Gᶜ the blue one, and cycleCliqueRamsey m n is the least N with RamseyProperty m n N. We did not build or run the Lean.

What this page checks

ramsey.js is the only copy of the maths, and ramsey.selftest.mjs holds it to 3,675 checks.

  • The lower bound. The extremal colouring has no red C_m and independence number exactly n − 1, for every case up to 24 vertices. The 5-cycle gives R(C₃, K₃) > 5.
  • Small cases. Exhaustive search gives R = 6, 7, 9, 11 for (3,3), (4,3), (5,3), (6,3), and the page adds (7,3) = 13 and (4,4) = 10. The incremental cycle test matches a literal one on random graphs.
  • The finite search.
    • The pattern recursion and the paper's generating function both give the paper's counts for all 42 pairs (k, t), 3,099 in total. The paper's worked example (k = 5, t = 3) forbids d = 1, 2.
    • Our independent implementation of the rules returns the paper's output table: 3,049 patterns with output 1, 50 with output 2, none unresolved.
    • For every one of the 3,099 patterns, the outcome, the initial forbidden flags and each strengthening round are identical to the release's traces.
    • Every witness in those traces is valid against data rebuilt here, and tampered witnesses are rejected.

Not checked: the structural part of the proof (Sections 2–8). That covers the reduction to graphs with an expansion property, the clique bound t ≥ ⌊k/2⌋, the cases k = 3, 4, and the argument for t ≥ 9. Those are proofs in words, and the Lean development covers them. The finite search is only as good as the rules it applies, and the rules come from the paper.

A note on independence: our implementation and the release's two Python programs share the paper's rules. That is the point, since the rules are proved in the text. They share no code. The release's Python and its trace file are third-party data. We read the trace file and never ran their code.
