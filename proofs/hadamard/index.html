Every row of a circulant matrix is the row above it shifted one step to the right, so the whole matrix is one row of n signs. It is Hadamard if every pair of rows is orthogonal, which makes H·Hᵀ zero off the diagonal. That off-diagonal entry is the row's correlation with its own shift by t, P(t). Try to make them all zero. Search flips signs greedily from many random starts. Only n = 4 ever reaches 0.

A Barker sequence is a string of ±1 whose correlation with every non-cyclic shift of itself is −1, 0 or +1. Radar uses them to sharpen pulses, and the original 802.11 Wi-Fi spreads every bit with the length-11 one. Lengths 2, 3, 4, 5, 7, 11 and 13 have been known since the 1950s. Odd lengths beyond 13 were ruled out in 1961. Even lengths were the open case, because a long even Barker sequence is a circulant Hadamard row. So the 2026 theorem closes it.

The search fills the sequence from both ends at once. Once the first d and last d signs are set, the correlation at every shift of n − d or more is fixed, so a branch dies as soon as one of them exceeds 1. It is checked against brute force over all 2ⁿ sequences up to n = 16, and it covers every length up to 40 on every change.

Which orders n were still possible, condition by condition, up to 10,000:

The first two conditions are short arguments this page checks. The row sum s of a circulant Hadamard row satisfies s² = n, because both sides count every ordered pair of positions. And any Hadamard matrix of order above 2 has order divisible by 4. The other two are Turyn's 1965 theorems, cited and not re-proved here. Logan and Mossinghoff (2017) then ruled out all but 4,489 orders up to 4·10³⁰ by computer. No finite search can finish the job. The 2026 paper claims every one of them is impossible.

The question

A Hadamard matrix is an n×n grid of +1s and −1s whose rows are pairwise orthogonal: any two agree in exactly half their places. They exist in many orders, and are conjectured to exist for every multiple of 4. A circulant one asks for more: every row is the previous row shifted by one. Order 4 has one, the row + + + −. In 1963 Herbert Ryser conjectured that there are no others beyond the trivial order 1.

The same question hides behind Barker sequences. A long even-length Barker sequence would give a circulant Hadamard matrix, so settling Ryser settles which lengths of Barker sequence exist.

The 2026 claim

A paper dated 23 September 2026, written by an internal OpenAI model and released on 6 October in a collection of 722, proves Ryser's conjecture. As a corollary, Barker sequences exist exactly at lengths 2, 3, 4, 5, 7, 11 and 13. The argument is algebraic. A circulant Hadamard row is a cyclic difference set with parameters (4u², 2u² − u, u² − u). The paper compares character values of that set in cyclotomic rings and reaches a contradiction for every u > 1. Several earlier claimed proofs exist (2016–2025); the paper lists them.

How it was checked

The main theorem is formalized in Lean. The release ships the statement as a separate file, checked by its Comparator tool against Lean's three standard axioms:

def IsCirculant (H : RealMatrix n) : Prop :=
  ∃ h : Fin n → ℝ, ∀ i j, H i j = h (j - i)

def IsSignHadamard (H : RealMatrix n) : Prop :=
  (∀ i j, IsSign (H i j)) ∧
    H * H.transpose = (n : ℝ) • (1 : RealMatrix n)

theorem exists_iff_order_one_or_four (n : ℕ) (hn : 0 < n) :
    ExistsRealCirculantHadamard n ↔ n = 1 ∨ n = 4

The library also contains a challenge file for the even-length Barker statement, but that one is not in the release's list of formalized main results, so this page does not count it. We did not run Lean ourselves, and the paper is a preprint.

What this page checks

hadamard.js is the only copy of the maths, and hadamard.selftest.mjs holds it to 1,513 checks:

  • The Lean condition H·Hᵀ = nI, computed as a real matrix product, matches the paper's autocorrelation form.
  • The identities (Σh)² = Σ P(t), P(t) ≡ n (mod 4), P(t) = n − 4k + 4N_D(t) and P(t) = C(t) + C(n − t) all hold.
  • Brute force over all 2ⁿ rows finds circulant Hadamard rows only at orders 1 (2 rows) and 4 (8 rows), up to n = 20.
  • Every sequence in the paper's Barker table checks out, and the exhaustive search finds Barker sequences at exactly the seven lengths up to 40.

None of that proves the theorem. The smallest order Turyn's 1965 conditions leave open is 900: a row of 900 signs, far beyond any exhaustive search, and only the first of 4,489 such orders below 4·10³⁰ that needed a real argument.
