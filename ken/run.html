The Standard Run

Six turns in four stages. Use this shape for every comparison.

Written to the structural rules of ASD-STE100 · runshape.mjs
About the language of this page

This page is a test. It follows the structural rules of ASD-STE100 Simplified Technical English. It does not follow the dictionary rule. Part 2 of that specification has a licence, and we do not hold one.

This page is therefore not in Simplified Technical English. It satisfies a subset. Section 6 gives the measurement.

1Purpose

This procedure gives the standard run. Use it for each comparison that this programme publishes. A fixed shape makes two runs comparable. It also makes the cost countable before you spend it.

2The shape

Table 1. The four stages.
StageNameAgentsTurnsRole
1Setup11Block. Prepares the state.
2Wave A22Treatment. A matched pair.

The run has six turns. It has four stages. No stage uses more than two agents.

3The reason for two agents in a wave

Give the two agents in a wave the same state. Then the wave is a matched pair. A matched pair removes the task difficulty from the difference between the two conditions. This cuts the runs you need by a factor of (1 − ρ).

The saving is not automatic. It depends on how you dispatch the wave. Give the two agents different state. The wave then becomes two independent draws. The saving is then lost.

Warning

Do not vary the brief between the two agents in one wave. Vary only the condition under test. If you vary both, you cannot separate them.

4Procedure

4.1 Before the run

  1. Write the scorer. Write it before the brief.
  2. Score the current code with the scorer. Confirm that it fails.
  3. Score a minimal correct answer. Confirm that it scores full marks.
  4. Set the number of runs. Use costInRuns() in runshape.mjs.
  5. Fix the stopping rule. Write it down before the first turn.
  6. Name the person who does the human tier. Give a date.
  7. Simulate the design. Report what the simulation gives.

4.2 During the run

  1. Run stage 1. Record the state that it produces.
  2. Dispatch wave A. Give both agents the same state.
  3. Record which agent got which condition.
  4. Wait for both agents. Do not start stage 3 early.
  5. Dispatch wave B. Give both agents the same state again.
  6. Run stage 4. Collect every output.

4.3 After the run

  1. Report the score variance across cells.
  2. Report the number of distinct score values.
  3. Report the share of cells at the maximum.
  4. Stop here if more than 70% of cells sit at the maximum. The run did not discriminate.
  5. Report the spread within a cell next to the difference between cells.
  6. Name each signal that did not fire. Put the names in the report header.
  7. Check each field that orders the report. Report a field that failed.
