# attractor

Bodies made of strange attractors. Plain ES modules, no dependencies; node and browser alike.
Drawn live at `studio.mino.mobi/avatar/` (Attractor Bodies), from a copy in `studio/vendor/attractor/`
(`node scripts/sync-dataviz.mjs --write`: edit here, never the copy).

| file | what |
|---|---|
| `lib/space.js` | the space: Sprott's general quadratic flows (30 coefficients, a 30-letter code), the famous named flows, RK4 `integrate`, `lyapunov` (Benettin), `dimension` (Grassberger–Procaccia correlation dimension), `describe` (principal axes, extents, fill), `discover(seed)` (search until a code is bounded, chaotic AND fractal) |
| `lib/bestiary.js` | GENERATED by `tools/bestiary.mjs`: 240 found attractors + the 10 named, with their shape |
| `lib/avatar.js` | `character(seed, over)` → a body spec for packages/figure, an attractor per part class chosen by fit, a palette, a style; `build` realises it; `frames(J)` from the rig's joints; `place` a point (on the surface, swirling, then `thought` of the way into its orbit) |
| `lib/draw.js` | `makeLight` (a float light buffer, JS glow, hue-keeping tone map) and `drawAvatar` (each streak a continuous thread) |

The search, and what it taught (2026-09-26): a positive Lyapunov exponent alone let slow limit cycles
through (most "finds" were loops; a long loop's exponent estimate is noise). The correlation dimension is
the second test: a loop is 1, a sheet 2, a strange attractor fractional. The named flows measure
1.4–2.3 (Lorenz 2.1). With both tests about one random code in 1100 passes, ~0.3 s a find in node.
