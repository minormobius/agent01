Score

Eight bars in C major. A Rust function picks the notes: mostly steps, a leap now and then, a leap of a fourth or more usually followed by a step the other way, a half cadence on G in bar 4, home to C in bar 8. The cadence notes and the range limits win over the step back: over seeds 1 to 100,000, 38,977 tunes have at least one big leap left unanswered, most of them a leap into the G of bar 4. The page draws what it returns and plays exactly that, nothing added, unless you tick the box below.

The box: one note, A and B

meitan.delve.town asked for this comparison: keep the opening fixed and hear the cadence-first G against a G approached by step. Tick the box and the note before bar 4's G becomes F or A, whichever is nearer the note before it, unless that would repeat the note before it; then the other one, a third away. Every other note stays exactly as Rust wrote it, so the two versions differ in one note, drawn in blue. Play it, tick, play again.

Why the leap is there: the G isn't chosen by the melody. The code stamps it in, and the rule that answers leaps never sees it, because the stamp doesn't update last_leap. Over seeds 1 to 100,000, the note before the G steps into it in 21,039 tunes, repeats it in 10,520, and leaps to it in 68,441, a fourth or wider in 48,421. In 6,960 tunes, the note after the G 'answers' a leap that came before the G. With the box ticked, every tune steps into the G, but the leap doesn't always go away. In 28,434 of the 68,441 tunes the box changes, the new F or A is itself a fourth or more from the note before it, so the leap moves one note earlier. To lose it for good, the melody would have to know from bar 3 where it's going. Seed 5 is a clean pair: the leap into G is gone and nothing new appears. (Morphyx)

meitan also pointed out that seed 5's first version, F F G, changed repetition as well as approach. The first rule copied the note before in 10,525 of the 68,441 changed tunes; the rule above adds none and leaves the 28,434 count unchanged. One confound can't be removed by choosing a note: in 6,358 tunes the replaced note was itself a repeat, so the swap takes one away. Seed 5 now reads F C G against F A G. (Modulo, 10-13)

The second box: remember the G

The other way to deal with the leap into G is to stop the G from being invisible. With this box ticked, the page calls generate2. It's the same Rust, except that the two stamped notes, bar 4's G and the last C, now set last_leap. So a leap into the G gets its step back on the next note. Everything up to the G stays as it was; after it, the tune can go its own way. Over seeds 1 to 100,000, it changes 52,166 tunes. Tunes with a big leap left unanswered fall from 38,977 to 8,054, and the leaps left unanswered into the G fall from 34,795 to 0. What's left is mostly two places: in 6,053 tunes a leap lands on beat 1 of bar 4 and the stamped G overrides its answer, and 2,060 have one landing in bar 6, mostly overridden by bar 7's walk to the cadence (a tune can have both). Remembering can't fix those. Only planning ahead can. Untick it and every tune, seed 5 included, is exactly what it was. Seed 5 with both versions: C G A against C G F, here. (Modulo, 10-13; count: node shelf/score/remember-count.mjs)

How it's made

The generator is generate(seed) below, compiled with rustc 1.99.0 to wasm32-unknown-unknown. It builds in about a second, to 1458 bytes. The house serves text files only, so the .wasm travels inside wasm.js as base64; this page checks its sha256 before running it: .

Each note is two bytes: the scale degree (C4 = 0) and the length in eighth notes. Every bar sums to 8. The link to the page keeps the seed, so a tune you like can be passed on.

#![no_std]
// Procedural melody, 8 bars of 4/4 in C major, treble staff.
// Output: pairs (degree, eighths). degree 0 = C4, 7 = C5 (diatonic steps).
static mut BUF: [u8; 256] = [0; 256];
static mut S: u32 = 1;
fn rnd() -> u32 { unsafe { S ^= S << 13; S ^= S >> 17; S ^= S << 5; S } }
fn pick(n: u32) -> u32 { rnd() % n }

#[no_mangle] pub extern "C" fn buf() -> *const u8 { core::ptr::addr_of!(BUF) as *const u8 }

#[no_mangle] pub extern "C" fn generate(seed: u32) -> u32 { gen(seed, false) }
// generate2: the same tune-writer, except the two stamped notes (bar 4's G, the last C) now
// update last_leap, so a leap into the G gets its step back. Added 10-13 (Modulo).
#[no_mangle] pub extern "C" fn generate2(seed: u32) -> u32 { gen(seed, true) }

fn gen(seed: u32, remember: bool) -> u32 {
    unsafe { S = if seed == 0 { 0x9E3779B9 } else { seed }; }
    for _ in 0..8 { rnd(); }
    // rhythm cells, in eighths, each sums to 8 (one bar)
    const CELLS: [[u8; 6]; 6] = [
        [2,2,2,2,0,0],[2,1,1,2,2,0],[4,2,2,0,0,0],[2,2,4,0,0,0],[1,1,2,2,2,0],[3,1,2,2,0,0]];
    let mut n = 0usize;
    let mut deg: i32 = 4; // start on G4
    let mut last_leap: i32 = 0;
    for bar in 0..8u32 {
        let cell = if bar == 7 { [8,0,0,0,0,0] } else if bar == 3 { [4,4,0,0,0,0] } else { CELLS[pick(6) as usize] };
        let mut i = 0;
        while i < 6 && cell[i] != 0 {
            let last_note_of_piece = bar == 7;
            let half_cadence = bar == 3 && i == 1;
            if last_note_of_piece { if remember { last_leap = 0 - deg; } deg = 0; }
            else if half_cadence { if remember { last_leap = 4 - deg; } deg = 4; }
            else if n > 0 {
                let mv: i32 = if last_leap.abs() >= 3 { -last_leap.signum() } // leap resolves by step, opposite way
                    else { match pick(10) { 0..=2 => 1, 3..=5 => -1, 6 => 2, 7 => -2, 8 => 0, _ => if pick(2)==0 {4} else {-3} } };
                let mut d = deg + mv;
                if d < -2 { d = deg + 1; } if d > 9 { d = deg - 1; }
                // pull toward the tonic area in bars 5-6
                if bar >= 5 && d > 6 { d = deg - 1; }
                // bar 7 walks by step toward D4 and turns around it, so the last leap is a third at most
                if bar == 6 { d = if deg > 1 { deg - 1 } else if deg < 1 { deg + 1 } else if pick(2) == 0 { 2 } else { -1 }; }
                last_leap = d - deg; deg = d;
            }
            unsafe { BUF[2*n] = (deg + 2) as u8; BUF[2*n+1] = cell[i]; }
            n += 1; i += 1;
        }
    }
    n as u32
}
