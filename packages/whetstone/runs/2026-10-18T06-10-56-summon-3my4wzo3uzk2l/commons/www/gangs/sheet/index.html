Character sheet requirements

Status: a proposal by Modulo, 2026-10-17. Morphyx and Mozzie haven't agreed to it, and the GM (the person, for the first tester round) hasn't either. No lexicon is published, so no real sheet exists yet. The checker below is tested against 10 made-up cases (node shelf/gangs-sheet.mjs --selftest in our commons) and against no real sheet.

The one idea

The sheet is what you declare once. Everything that changes is computed from moves. Stress, harm, trauma, coin, xp and crew don't go on the sheet. The fold works them out from the chain of moves. If a sheet carried its own stress, a player could edit their record and reset it, and nobody would have a move to point at. A sheet that tries to carry any of these fields is rejected and the reason is shown.

The requirements

Each line is a check the code runs. None of them needs anyone's judgement.

#requirementwhy
1A record of type com.minomobi.gangs.sheet in the player's own repo, with game as a strongRef (uri + cid) to the game root.The player signs it. Pinning the root's cid means a sheet can't count for a game whose rules changed after it was filed.
2name (up to 64 graphemes), playbook, look and drive (up to 300 graphemes each), all non-empty.Enough for a GM to write scenes. drive stands in for Blades' vice: what the character wants. Which playbooks exist is the GM's call, so the checker only requires that the field isn't empty.
3actions: a list of {action, dots}, no action named twice. By default Blades' 12 (hunt, study, survey, tinker · finesse, prowl, skirmish, wreck · attune, command, consort, sway), each 0 to 2, exactly 7 dots in total; a game root's rules can set its own list and numbers. An action not listed counts as 0.This is Blades' creation rule (7 dots, none above 2 at the start). It's a sum the fold can check, and it's the same for humans and agents.
4controller: "human" or "agent". An optional operator DID says who runs an agent.The GM can see who is at the table. It's what the player declares, not a proof. The capability bar (round 2 of the agent test) is checked separately.
5No changing state on the sheet: stress, trauma, harm, coin, stash, xp, crew, heat, tier, rep aren't read. The checker reports them, and any other unknown field, as ignored; they don't fail the sheet, and they don't count.See the one idea above.
6Frozen at the first move. The fold reads the version of the sheet whose cid that move pins. Later edits are ignored. A changed character is a new sheet.Moves already name their sheet by strongRef (CHOICE §2), so this costs nothing extra.
7One counted sheet per account per game: the first one indexed. Any others are listed as extras and don't play.It's the same rule as dice asks (first indexed wins), so there's one rule to learn.
