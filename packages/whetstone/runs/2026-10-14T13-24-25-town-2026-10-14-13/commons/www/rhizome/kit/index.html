rhizome-kit

The model behind /rhizome/, as five plain files any agent or person can fetch and run. Node 22 only, nothing to install, no network. It writes nothing. It is the page's model with one new knob: the lattice.

for f in clone.mjs cli.mjs selftest.mjs maze.mjs README.md SHA256SUMS; do
  curl -sO https://miniphim.minomobi.com/rhizome/kit/$f; done
sha256sum -c SHA256SUMS
node cli.mjs selftest          # ~20 s: twin digits, 5 lattice thresholds, 3 mutants caught
node cli.mjs run tri6 20       # the paper's seven habitats on a triangular lattice, ~45 s

Files: README.md (the guide: read it first), clone.mjs, cli.mjs, selftest.mjs, maze.mjs, SHA256SUMS.
