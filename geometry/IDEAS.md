# Geometry pack — ideas

Interactive sites on extremal-geometry conjectures: each follows the same shape (one interactive viz, growth/history view where useful, prose docs) with a single-file static HTML scaffold. Style varies slightly per page — distinctive accent colour, sister-site cross-links in the header, optional play tab. Series cross-referenced through the root landing page's `data` category.

## Roadmap — the loop / diagram / statistical-mechanics vein

A second track opened with `/meander/` and `/temperley-lieb/`: not "extremal bound, long climb, open endpoint" but **"poke a simple object, watch deep structure fall out."** Future picks in this vein should hit all four marks:

- **A dead-simple object you can poke** — arcs across a line, tiles in a grid, crossings in a knot.
- **…that secretly carries deep structure** — an algebra, a limit shape, a topological invariant.
- **…with a physics-grade punchline** — CFT, quantum gravity, modular forms, integrability, universality.
- **…one manipulable canvas** with a verb (*find / sample / wrap / verify*) and a clear verdict.

The spine: **meander** (count the loops) → **temperley–lieb** (the algebra of loops, and how it wraps onto a torus). Three tracks hang off it.

**Track 1 — the loop/tiling family (direct descendants):**
- **`/aztec/`** — Aztec diamond domino tilings + the **Arctic Circle theorem** (Jockusch–Propp–Shor 1995). Sample a uniform random tiling by *domino shuffling* (EKLP), watch the frozen corners + disordered center crystallize into a circle. The dimer model = a cousin of TL's loop model; the limit-shape reveal is the biggest "wow" in the space. **✓ SHIPPED — see Built table.**
- **`/jones/`** — Jones polynomial via the **Kauffman bracket**: draw a knot/braid, resolve each crossing by the skein `A·)( + A⁻¹·≍`, state-sum to the polynomial. The literal payoff of TL's Markov trace; tightest possible sequel to `/temperley-lieb/`.
- **`/six-vertex/`** — ice model arrows → height-function landscape → alternating-sign matrices → its own arctic curve. Bridges TL to the integrable-lattice world.
- **`/catalan/`** — the Rosetta hub: the ~10 things Catalan numbers count (Dyck paths, triangulations, non-crossing matchings, trees, parenthesizations) **morphing into each other** via live bijections. Cheap, foundational, ties meander + TL at the root.

**Track 2 — limit shapes & universality:**
- **`/lozenge/`** — lozenge tilings / boxed plane partitions: MacMahon's box formula, the arctic *ellipse*, a rotatable 3D cube-stack. Dimer model in its second costume (pairs with `/aztec/`).
- **`/rsk/`** — Robinson–Schensted–Knuth: type a permutation, watch the bumping build two Young tableaux; longest-increasing-subsequence; the Tracy–Widom punchline.
- **`/kpz/`** — TASEP → KPZ: hopping particles, the growing interface, `t^{1/3}` fluctuations, the universality class.
- **`/sandpile/`** — abelian sandpile: drop sand, topple, the fractal identity element; self-organized criticality.

**Track 3 — the torus / modular vein (where "wrapping" lives):**
- **`/cohomology/`** — discrete Hodge decomposition on a punctured plane: the cheapest place in the pack where a topological invariant is *computed* rather than argued about. **✓ SHIPPED — see Built table.**
- **`/modular/`** — fundamental domain of SL(2,ℤ), the j-function, q-expansions. A torus *is* ℂ/Λ — the deep reason the TL torus matters; wires to `/viazovska/`'s modular forms and to moonshine.
- **`/farey/`** — Farey tessellation / Stern–Brocot tree / Ford circles: the modular group as a tessellation, rationals as a tree.
- **`/apollonian/`** — Descartes' circle theorem, integer curvatures, number theory hiding in a packing.
- **`/penrose/`** — aperiodic order via cut-and-project from a 5D lattice shadow; inflation rules; quasicrystals.

## Roadmap — the label and the law

A third vein, aimed at one question: **which parts of a description are real, and which are only labels?** Recolour a graph, relabel a Latin square, re-gauge a lattice, change the basis of a lattice or a neural network: the description changes and the object doesn't. The pages below teach how to tell the two apart, and they get the tools for it from cryptography, mechanics, probability and logic. The arc runs from *relabeling* through *commitment* and *conservation* to *self-reference*: a system reading its own source, and the hard limit on that.

Each page must pass the loop-vein test above: a simple object to poke, deep structure, a punchline with weight, and one verb with a verdict. Each gets an engine module shared byte-for-byte with its selftest, like `/cohomology/`.

**Unit A — the label (what a relabeling cannot change)**

1. **`/burnside/`** — counting up to symmetry. Colour a necklace or a cube's faces with k colours and count the distinct results, first up to rotation and then also up to **permuting the colours themselves**. *Verb:* colour, then press "quotient". *Verdict:* the brute-force orbit count equals Burnside's average of fixed points. *Selftest:* necklace counts against the closed form (1/n)Σ_{d|n} φ(d)kⁿᐟᵈ (OEIS A000031 for k=2); cube face colourings 10, 57, 240 for k=2, 3, 4. *Sources:* Frobenius 1887; Burnside 1897; Pólya 1937.
2. **`/latin/`** — Latin squares. Fill an n×n grid so each symbol appears once per row and column. That is exactly a proper colouring of the rook's graph, and exactly the multiplication table of a quasigroup. Relabel rows, columns and symbols (isotopy) and watch which squares turn out to be the same square. *Verdict:* "isotopic to the cyclic group table" or "not a group". *Selftest:* totals 1, 2, 12, 576, 161280 (A002860) and reduced counts 1, 1, 1, 4, 56 (A000315) by exhaustive search to n=5. *Punchline:* Euler's 36 officers. No orthogonal pair exists at order 6 (Tarry 1900), Euler's broader conjecture fails for every other n ≡ 2 mod 4 (Bose–Shrikhande–Parker 1959), and the order-6 problem has a solution once the officers are quantum (Rather et al., *PRL* 128, 080507, 2022). *Sister:* `/capset/` (another order-3 object).
3. **`/gauge/`** — ℤ₂ lattice gauge theory on a small grid. Every link carries ±1. Click a site to gauge-transform it, which flips all four of its links: the picture changes and every plaquette product stays put. *Verdict:* plaquette field unchanged, live. A Metropolis tab samples the theory. In 2D, Wilson loops follow an **area law** at every coupling, exactly, so the 2D theory always confines. A small 3D lattice tab shows Wegner's transition: the area law gives way to a **perimeter law** at β_c ≈ 0.761, a phase transition with no local order parameter (3D ℤ₂ gauge is dual to the 3D Ising model). *Selftest:* gauge invariance of every observable over random transformations; on 2D open lattices, ⟨P⟩ = tanh β and ⟨W⟩ = tanh(β)^area, both exact; the 3D crossover on the right side of β_c. *Punchline:* Elitzur's theorem (1975) says a local gauge symmetry can never break spontaneously, so the label can never be measured. *Sources:* Wegner 1971; Wilson 1974; Elitzur 1975; Kogut 1979 (review).

**Unit B — the commitment (hide a choice, prove something about it)**

4. **`/commit/`** — Blum's coin flip by telephone. Alice commits to a bit with a hash (SubtleCrypto SHA-256), Bob calls heads or tails, and Alice opens. Tabs try to cheat each side and show what stops each cheat. *Verdict:* binding held / hiding held. *Punchline:* no commitment is both perfectly hiding and perfectly binding, and the page shows the counting argument for why. *Source:* Blum, "Coin flipping by telephone", CRYPTO 1981.
5. **`/zk-colour/`** — a zero-knowledge proof of graph 3-colouring. You are the prover holding a colouring. Each round you **shuffle which colour is which**, commit to every vertex, and the verifier opens one edge. The shuffle is what makes the colours carry no information. *Verdict:* the soundness meter (a cheater survives a round with probability at most 1 − 1/|E|, compounded over rounds), plus a **simulator** tab that forges transcripts without knowing any colouring, indistinguishable from the real ones. That last part is the actual definition of zero knowledge, and it is the reason for the page. *Selftest:* exhaustive soundness on small graphs; simulator and real transcripts produce the same distribution of opened colour pairs (χ² test). *Punchline:* 3-colouring is NP-complete, so every NP statement has a zero-knowledge proof. *Source:* Goldreich–Micali–Wigderson 1986 (*JACM* 1991). *Sister:* `/hadwiger/`.
6. **`/lll/`** — lattice basis reduction. Drag a skewed 2D basis and Lagrange–Gauss reduction finds the short, nearly square one: same lattice, better coordinates. The n-dimensional LLL runs step by step with its size-reduction and swap moves shown. *Verdict:* Lovász condition met (δ = 3/4). *Punchlines:* recover the minimal polynomial of a number from its decimals (x² − x − 1 from 1.6180339887); break a low-density knapsack cipher. *Selftest:* basis determinant preserved; output satisfies size-reduction and Lovász; integer relations recovered for known algebraic numbers. *Sources:* Lenstra–Lenstra–Lovász, *Math. Ann.* 261 (1982); Shamir 1982 (Merkle–Hellman); Lagarias–Odlyzko, *JACM* 1985. *Sister:* `/viazovska/` (E₈ as a lattice).

**Unit C — the conservation law (what nothing can create or destroy)**

7. **`/liouville/`** — phase-space area. Drop a blob of pendulums into phase space and let it flow: it shears into a filament and keeps its area exactly. Switch the integrator to explicit Euler and the area grows. *Verdict:* area ratio, live, by the shoelace formula. *Selftest:* on the harmonic oscillator, explicit Euler grows area by exactly (1+h²) per step and symplectic Euler by exactly 1. Both are closed forms. *Punchline:* Hamiltonian flow has no attractors, which gives Poincaré recurrence and explains why naive simulations heat up. *Sources:* Liouville 1838; Poincaré 1890; Hairer–Lubich–Wanner, *Geometric Numerical Integration*.
8. **`/dutch-book/`** — coherence. Price bets on A, B, A∧B and A∨B. If the prices break the probability axioms, the engine builds a set of bets that takes your money in every outcome. *Verdict:* coherent, or here is the book and its guaranteed profit. *Selftest:* incoherent prices always yield a book (a separating hyperplane over the outcome atoms); coherent prices never do. *Source:* de Finetti, "La prévision", 1937.
9. **`/maxent/`** — Jaynes's dice. All you know is that the mean roll is 4.5: which distribution should you believe? Drag rival distributions that meet the constraint and compare their entropies. The maximum is the exponential family, which is the Boltzmann distribution. A second tab compresses text and sets Huffman code lengths against the entropy bound. *Selftest:* the Lagrange multiplier solved against a bisection reference; Huffman lengths within one bit of H. *Sources:* Shannon 1948; Jaynes, *Phys. Rev.* 106 (1957).

**Unit D — the self-reference (a system reading its own source)**

10. **`/superposition/`** — a network learns five features through two neurons. Train a tiny ReLU autoencoder in the browser on sparse features and watch the features arrange themselves as a **regular pentagon**. The neuron basis is a label and the geometry is the law. Sparsity is the slider, and the phase change between "drop features" and "pack them in" is the verdict. *Selftest:* at high sparsity, five features in two dimensions converge to a pentagon (pairwise angles 72° ± tolerance) over fixed seeds. *Source:* Elhage et al., "Toy Models of Superposition", 2022. This is the closest of the ten to how model interpretability works in practice.
11. **`/quine/`** — fixed points. Build a program that prints its own source, then see that it is the same diagonal trick as Cantor, Gödel and Turing. *Verdict:* output == source, checked byte for byte. *Punchline:* Lawvere's fixed-point theorem is one argument behind all four, and it says exactly where self-description has to stop. *Sources:* Kleene 1938; Lawvere 1969; Yanofsky, *Bull. Symb. Logic* 9 (2003).
12. **`/open-source-pd/`** — program equilibrium. Prisoner's-dilemma bots that can read each other's source. CliqueBot cooperates only with exact copies of itself. FairBot cooperates if it can *prove* the other cooperates, and Löb's theorem makes two FairBots cooperate. Write bots as modal formulas and let the engine compute the outcome. *Verdict:* the payoff matrix of every pairing. *Selftest:* the published outcome table (FairBot×FairBot = C, FairBot×DefectBot = D, PrudentBot behaviour), computed by fixed points over GL Kripke frames. *Sources:* Tennenholtz 2004; Löb 1955; Barasz et al., arXiv:1401.5577 (2014).

**Build order.** 4 → 5 is the spine: commitment, then zero knowledge. It is the most self-contained pair and has the strongest single verdict. After that 2, 6, 7, then the rest. 1 and 2 can share a `group.js` engine (permutation groups, orbit enumeration). 4 and 5 share `commit.js`. Each unit's hub is a short entry on `/geometry/`, not a new page.

**Out of scope here: these are instruments.** Randomness harvested from the drift between two clocks, and active noise cancellation, are both things a phone can do live with its own speaker, microphone and timers. They belong on `sci.mino.mobi` beside `/sonar/`, not in this pack.

## Pattern notes

Every entry should have:

- Single-file static HTML page in its own top-level directory (`/<name>/index.html`).
- Header: crumb to `mino.mobi`, h1, subtitle, sister-site crossref strip.
- Format bar (theme + reveal-all) if there's coloring or hover-driven viz.
- Tabs: at least one interactive viz tab, optional growth/history/play tabs, docs tab.
- Distinct accent colour from the siblings (record above).
- Entry added to root `index.html` PROJECTS array (category: `data`, age: `hot`).
- Cross-links to sister sites in `<footer>`.
- Math validated in a smoke test (run inside the deploy commit body).

## Anti-patterns

- **No server-side compute.** Everything static HTML + canvas JS. The polynomial-method demos in particular tempt one toward server-side SAT solvers; resist.
- **Don't pick problems that need > 500 vertices to demonstrate.** The page becomes click-uncolourable. (Reveal-only static rendering is fine — see hadwiger's plan for the actual de Grey graph.)
- **Don't draw a log-log growth chart for problems with two data points.** A prose timeline reads better.
- **Don't overclaim.** Be honest when a procedural construction doesn't quite reach the claimed bound (see hadwiger's "Moser flower"); the page can still be educational.
