The solvers behind every chapter, what each was checked against, the compute they ran on, and how to run them yourself.

How this book is made

Everything in these chapters is computed by code anyone can read, and most of it can be re-run in a browser. Six rules make that hold:

  1. Our world is the control. Every solver is written for any number of dimensions and run on ours first, against measured or published answers. Only then is it run in four.
  2. No dependencies. Plain JavaScript modules, the same ones in a browser and in node. The live views on these pages run the same code that produced the numbers.
  3. Every number comes from the code. The calculations write their results to data files, and the pages are generated from those files: nothing on a page is typed by hand.
  4. Everything stated is checked. A self-test of 75 groups of checks, about a minute and a half, recomputes samples of every result and checks each method against known answers. It runs on every change.
  5. Long runs go to a free compute runner, below, and every run is logged.
  6. Mistakes stay in the text. When a check fails, the fix and the failure are both written up (the search chapter's hydrogen fluoride).

The compute runner

A calculation longer than a few minutes runs on GitHub's free runners: 4 cores, 16 GB and up to 6 hours each, up to 20 at once. A run is a short file listing commands, each a tool and plain words, grouped four to a runner. Pushing it starts the run. Each tool saves its progress every few seconds to a data branch, so a run cut at its deadline resumes where it stopped, and every run's logs are kept there with the commit it ran. The results come back as data files, and the pages are regenerated from them.

The methods

Each method: what it computes, how, what checks it (the self-test's numbered checks, by name), its code, where it's used, and its limits.

Atoms: the self-consistent field

Every atom from hydrogen to element 140 (ours to 36, the check), in both worlds: its electron configuration, energies, sizes and ionization.

The radial equation in d dimensions has the centrifugal term of l + (d − 3)/2, so one solver serves every dimension. It is solved by Numerov's method on a logarithmic grid, energies found by Sturm bisection on node counts. Many electrons are a self-consistent field: each feels the nucleus, the others' charge through the sphere-averaged kernel (1/max in 3D; k(min/max)/max in 4D, which has no shell theorem), and a local exchange term from the d-dimensional electron gas, with each electron's own share removed and Hund's rule for spins. The ground configuration is searched among candidates, and only converged fields count.

Hartree–Fock in any dimension

Molecules: their shapes, dipoles and hydrogen bonds, our water first as the check.

Hartree–Fock on Gaussian functions, with McMurchie and Davidson's integrals rebuilt for d dimensions: the Boys function F_n is replaced by G_n(T) = ∫₀¹u²ⁿ(1 − u²)^((d−3)/2) e^(−Tu²) du, which is F_n at d = 3. Correlation: MP2

What Hartree–Fock leaves out of a pair's binding: whether the tie between Xater and XH₃ survives it.

Møller–Plesset perturbation theory to second order on the closed-shell Hartree–Fock result, the cores frozen: E₂ = Σ (ia|jb)[2(ia|jb) − (ib|ja)]/(εᵢ + εⱼ − εₐ − ε_b), over occupied i, j and empty a, b, the integrals turned from basis functions to orbitals by a four-index transform (one pass over the unique integrals for every occupied orbital at once). Nothing in it depends on the dimension; that lives in the integrals. Pairs are counterpoise-corrected, each molecule alone in the pair's whole basis, as the Hartree–Fock ones are. The basis is grown by one recipe in both worlds (a second d, diffuse s and p, a second p on hydrogen, an f), and in our world checked against the standard aug-cc-pVTZ and aug-cc-pVQZ, computed at the same arrangements by PySCF. For open shells (atoms with unpaired electrons, triplet molecules) the same on an unrestricted Hartree–Fock result, each spin its own orbitals: same-spin pairs ½ Σ (ia|jb)[(ia|jb) − (ib|ja)]/D, opposite-spin Σ (ia|jb)²/D. Molecules without hydrogen are scanned bond length by bond length this way, counterpoise-corrected, each point started from the bare nuclei and from the two atoms' densities with spins parallel and antiparallel (and from the previous point's solution), the lowest kept; our F₂ and O₂ are the checks. Bond strengths come from atomization energies the same way (geometry by Hartree–Fock, energy by MP2, atoms by unrestricted MP2), hydrogen against gluorine on the same atom, our CH₄, CH₃F, H₂O, OF₂, HF and F₂ the checks (each within 2–12% of measured).

A polarizable force field, and crystals

Liquid and vapour, side by side

Where a gas condenses: its critical point; where a liquid of molecules boils.

Gibbs-ensemble Monte Carlo: two boxes trade volume and atoms (or rigid molecules, turned in random planes) until one is liquid and one vapour, at one temperature per run; the critical point is fitted to the two densities across temperatures. For molecules each box keeps its own Ewald sum (real space to half the box, the structure factor updated move by move): a truncated charge sum, good to 0.3 kcal/mol a molecule in our water, is off by 42 in 4D, because the pinned 1/r charges a wave of polarization as 1/k. The 4D pull reaches far, so the boxes are big and the tail is added for a uniform fluid; where a field carries 4D's charge–cloud terms (q c/r³, which cancel only over a whole molecule), the short-range terms are cut by molecule rather than by site. Each run starts with nearly every molecule in one box, melts it in place, then lets the boxes trade; the liquid is the denser box of each block's means, independent seeds are pooled, and Tc carries a bootstrap error over them.

Pauli's exclusion, derived

Why electrons can't share a state here, though the force between them isn't relativistic.

The free electron's 4 + 1 Dirac Hamiltonian has levels ±√(c²p² + m²c⁴). If electrons commuted, N of them could share one negative-energy wavepacket of width b; their pinned 1/r repulsion is at most √π/(4bν²) by Cauchy–Schwarz on the packet's amplitude (ν ≥ ½ its weight in those states), so at b = N² the energy is at most −Nmc² + √π/2 and has no floor. Only the half of spin-statistics that needs positive energy is used, not the locality the lens vacuum lacks.

Run it yourself

The code is public. With node (version 20 or later) and git, and nothing else installed:

git clone https://github.com/minormobius/agent01
cd agent01
node four/atom/test/atom4.selftest.mjs        # every check, about 90 s

Each tool's first lines say what it does and how to run it. A fork's own GitHub Actions can run the compute queue (.github/compute/atom4.json) the same way.
