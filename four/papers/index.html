How a paper gets made

Paper 1, being written in the open. Everything below is read from the paper's own files as they stand: the claims' values are recomputed from the baked table on every build, and a test fails the build if any claim stops holding. Nothing here is a description of the work written after the fact.

The rule

The paper's subject is a choice. In four dimensions the law between charges can't be inherited: Gauss's law leaves no atom, so one has to be picked, and what it costs has to be paid in the open. Paper 1 picks 1/r, says why, and measures what that choice does by solving the whole periodic table twice, once under the law and once with the shell theorem forced back on.

A number in the paper is never typed. It's read from a file the solver baked, and a test checks it against that file. The claims, the figures and eventually the text are generated, so the prose can't drift from the numbers. References are cited only once their details have been confirmed from the source or an index; seen-in-passing doesn't count. Anyone can solve the atoms again and get the same numbers to the last digit.

    The data

    Solve it again

    The reproduction re-solves the paper's atoms with the same function that baked them and compares, configuration exactly and energies to 10⁻⁴ hartree. It ships with the solvers in the open mirror (MIT), and the mirror's workflow runs the sample on every change.

    node papers/p1/reproduce.mjs                 # a sample: each 4D row's first, second and noble gas, and six of ours
node papers/p1/reproduce.mjs --z4=78,138     # chosen 4D elements
node papers/p1/reproduce.mjs --all           # all 176 (hours on one machine)

    Last run: 14 of 14 reproduced to the bit, 18 s on four cores (2026-11-04).
