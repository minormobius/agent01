A Portrait of the Artist as a Young Man

James Joyce, 1916. Nineteen movements, opened and closed in his own words — with a facing column naming whose idiom the narration is wearing. On the medieval tales of this site that column holds a translation. This book is already in English and still in somebody else's language, which is the harder problem and the more useful gloss.

Discourse graph

Where the medieval tales get Propp's thirty-one functions, this one gets Gérard Genette's five categories of narrative discourse — the morphology built on a modernist novel, for a book with almost no plot to morphologise.

Desire

Greimas's actantial model, and the term it lacks. The diagram wants an Object that is a thing and an Opponent who is a person; this novel has neither, so René Girard's mediator is set beside it.

Leitmotif index

No call-numbers, because there is no index to call them from. Twelve lexicons, counted off the text and normalised per 10,000 words — with every word-list printed, so you can disagree with it.

The epiphany ladder

Joyce's own structural unit, in place of the oral type-scene — and Kenner's observation that every chapter's exaltation is deflated by the opening of the next. Both sides of each join are verbatim.

The style curve

The layer the medieval apparatus cannot have. In a folk tale the style is a constant; in this novel the style is the plot, and it can be measured.

The mythograph
