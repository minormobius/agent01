# astra — GPT-6 Astra hype video (ExploitBench 100%)

A 43-second, portrait (1080×1920), full-brainrot hype video about one cell of
one screenshot: GPT-6 Astra's **100.0% on ExploitBench**. Parody. Pure static,
bundled into the root Pages deploy like `echo/` and `judge/` — served at
`mino.mobi/astra/`. Not a registry surface; nothing deploys it on its own.

## Files

| File | What |
|---|---|
| `index.html` | the whole video: one `<canvas>`, one timeline, procedural phonk beat + vine booms via WebAudio, Anton embedded as base64 (Latin subset, OFL) |
| `table.jpg` | the benchmark screenshot the video zooms into (row/column pixel coordinates are constants at the top of the script) |
| `gpt6-astra-hype.webm` | the rendered video (VP9 + Opus, 30 fps), regenerated by `record.mjs` |
| `record.mjs` | headless renderer — `node astra/record.mjs`, ~2 min, needs Playwright's Chromium |
| `webm-muxer.js` | vendored [webm-muxer](https://github.com/Vanilagy/webm-muxer) 5.1.4 (MIT), loaded only in render mode |

## How it works

Everything is a pure function of `t`. Live, the `AudioContext` is the clock
and `requestAnimationFrame` draws whatever frame `t` calls for; the browser's
`speechSynthesis` reads the TikTok-voice lines on top when it has a voice.
`?render=1` runs the same `buildAudio()` into an `OfflineAudioContext`, draws
each frame at `i / fps`, pushes it through WebCodecs (`VideoEncoder` VP9,
`AudioEncoder` Opus) and muxes in-page, so the render never depends on
wall-clock speed. `?frame=12.5` draws one frame for layout checks.

`CUES[]` is the single source for shakes, flashes *and* the one-shot sounds
(boom / hit / riser / scratch / tick / ding), so audio and picture cannot
drift. `SCENES[]` maps time ranges to draw functions.

## Quirks

- Real-time `MediaRecorder` capture in headless Chromium delivers a handful
  of frames per minute. That's why rendering is offline WebCodecs, not
  screen capture. Don't go back.
- `record.mjs` serves the directory over loopback: a canvas that drew a
  `file://` image is tainted and `VideoFrame` refuses it.
- Playwright's bundled ffmpeg can't remux VP9 (no `vp9_superframe` bsf) and
  has no audio encoders, so the muxing happens in the page.
- The bitrate is set by `KBPS` (default 1800; the committed file uses the default to
  stay well under Cloudflare's 25 MiB per-asset limit and keep the repo sane).
