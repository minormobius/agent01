# assets/fonts

The three faces of the site's design language (see `/mino.css`), fetched from
Google Fonts so the link card (`scripts/generate-og-card.mjs`) can render them
without a network, and available for self-hosting if the Google Fonts link ever
goes. Licences: Bricolage Grotesque and Source Sans 3 are SIL OFL 1.1; JetBrains
Mono is SIL OFL 1.1.
